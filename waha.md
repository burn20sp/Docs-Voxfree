# Waha (waha-plus)

> Documentação em construção — será detalhada futuramente.

Plataforma de conexão para WhatsApp (pesquisar "WAHA WhatsApp HTTP API" para
mais detalhes sobre o produto). Usado atualmente para testes de aplicação
com WhatsApp.
